# From Point A to B.C.

Dad's shortcut sends a father and son tumbling through history. A point-and-click adventure you can play in your browser.

**Play it:** https://n0tk3r.github.io/from-point-a-to-bc/

## Status

Early development. For now the site is a placeholder title screen while the game takes shape.

## Running it locally

It's a static site with no build step. Open `index.html` in a browser, or serve the folder and visit http://localhost:8000:

```
python3 -m http.server 8000
```
